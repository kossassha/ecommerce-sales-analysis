# E-commerce Sales Analysis

Аналитический проект по исследованию продаж интернет-магазина.

## Цель проекта

Проанализировать продажи интернет-магазина и определить:

- динамику выручки;
- наиболее прибыльные категории;
- лучшие товары;
- основные клиентские сегменты;
- эффективность каналов продаж;
- географию покупателей;
- возвраты и отмены.

## Technologies

- Python
- pandas
- NumPy
- SQL
- SQLite
- Jupyter Notebook
- Streamlit
- Plotly
